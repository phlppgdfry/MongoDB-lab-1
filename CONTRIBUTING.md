# Contributing

Thanks for taking an interest in Atlas Lab.

## Local development

1. Fork the repository and create a focused branch.
2. Install dependencies with `npm install`.
3. Copy `.env.example` to `.env` and configure MongoDB Atlas and Ollama.
4. Run `npm run check` before opening a pull request.
5. Keep changes small, documented, and free of credentials.

## Pull requests

Please describe the user-facing change, explain any configuration changes, and include tests for new behavior where practical. Pull requests run the GitHub Actions build and test check automatically.

## Scope

This is an educational showcase. Feature proposals should preserve the project's transparent architecture and should not introduce provider keys, database passwords, or generated build artifacts into source control.
